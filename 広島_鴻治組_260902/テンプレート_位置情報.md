# 現場テンプレート（位置情報だけ差し替え）

見た目・ループ・警報／天気／WBGT の仕組みは共通です。  
**変えるのは位置情報（`assets/site-config.js`）だけ**です。

## 新しい会場を作る手順

1. このフォルダ一式をコピーする（例: `広島_鴻治組_別現場`）
2. `assets/site-config.template.js` を `assets/site-config.js` にコピー（上書き）
3. `site-config.js` の ★ 項目だけ書き換える
4. ローカルで `index-4face.html` を開いて確認（Ctrl+F5）
5. 本番へは `index-4face.html` + `assets/` をまとめて上げる

`index-4face.html` 本体や CSS / JS のロジックは触らない。

## 書き換える項目（必須）

| 項目 | 役割 | 安芸区の例 |
|------|------|----------|
| `site.label` | 時刻下白帯の会場名・工事名 | 令和8年度 安芸南部山系…堰堤他工事 |
| `site.locationLabel` | 天気パネル等の短い地名 | 安芸区 |
| `moe.point` | 環境省 WBGT 地点コード | 67511（呉） |
| `moe.pointName` | 環境省の観測地点名 | 呉 |
| `moe.alertArea` | 熱中症アラートの府県名 | 広島県 |
| `moe.region` / `moe.prefecture` | 環境省の地域・県コード | 08 / 67 |
| `jma.amedasPoint` | 気象庁 AMeDAS（通常は `moe.point` と同じ） | 67511 |
| `jma.forecastArea` | 予報区域コード | 340000 |
| `jma.forecastLabel` | 予報表示名（`locationLabel` と同じで可） | 安芸区 |
| `jma.warnArea` | 警報 JSON の都道府県コード | 340000 |
| `jma.warnCity` | 警報の市町村コード | 3410300 |
| `jma.warnCityLabel` | 警報上段の市町村名 | 安芸区 |

任意: `site.address` / `geo` / `customer` / `jma.amedasSupplementPoint`（気圧など補完地点）

## コードの探し方

- 警報 API: `https://www.jma.go.jp/bosai/warning/data/r8/{warnArea}.json`
- 表示対象市: `warnCity` / `warnCityLabel`
- 設定の読み込み: `index-4face.html` が `./assets/site-config.js` を読み込む

## 触らないもの

- 色3段 / 白3段の CSS・JS
- ループ順・ホールド時間
- LED 512×128（4面）のレイアウト
- WEB と LED で見た目を分岐する変更
