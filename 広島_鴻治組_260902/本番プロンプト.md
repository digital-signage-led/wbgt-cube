## コピー用プロンプト

```text
あなたは LED キューブ用 WBGT サイネージ担当です。
対象は 株式会社鴻治組・熊野現場の本番 4面（512×128）。
既存の鈴中工業 4面テンプレート（index-4face.html）を現場差し替えする。庄原の広島_鴻治組は触らない。

【キャンバス】
- 本番: 4面 512×128。右端ロゴ列なし（layout-512）
- 列幅 128、ギャップ 0。勝手にレスポンシブ化しない
- 確認: ?layout512=1&native640=1 ／ 単体 ?only=1 〜 ?only=6
- 作業フォルダ: 広島_鴻治組_260902
- デプロイ先フォルダ名: hiroshima_koujigumi_kumano（庄原 hiroshima_koujigumi と別）
- 本番URL: https://digital-signage-led.github.io/wbgt-cube/hiroshima_koujigumi_kumano/index-4face.html?layout512=1&native640=1

【現場】
- 会社: 株式会社鴻治組
- 工事名: 令和7年度 安芸南部山系深山の滝川上流支川砂防堰堤他工事
- 現場事務所: 広島県安芸郡熊野町平谷2丁目19-7（〒731-4229）
- 画面の地点表示: 熊野町（町内に観測所はない）

【データ（変更禁止の原則。地点を変えるときだけ明示指示）】
- WBGT: 環境省 呉 67511。欠測フォールバックなし
- AMeDAS: 呉 67511。気圧など欠けは広島 67437 で補完
- 予報区域 / 警報区域: 340000
- 警報市区: 3430700 熊野町
- 出典: 気象庁・環境省データ
- GAS: 既存他現場と同じ exec URL
- キャッシュキー: hiroshima_koujigumi_kumano_signage_v1

【画像】
- 128面・縦型: ./assets/kohji_logo.png（マーク＋KOUJi。横長余白あり。128面は object-fit:cover で面いっぱい）
- 下帯・横型: ./assets/kohji_foot.png（マーク＋KOUJi＋株式会社＋鴻治組。上下余白を帯高さいっぱいに拡大）
- 緑十字: ./assets/green_cross.png（公式・緑地に白十字＋緑十字。128面は cover で面いっぱい）
- 画像は勝手に生成しない。届いた公式ファイルだけ使う

【再生順】
1. 時刻（シーン1）
2. 気象観測（シーン2）＋末尾ロゴ1面
3. 暑さ指数 / WBGT（シーン4）＋末尾ロゴ1面
4. 4日予報（シーン5）＋末尾ロゴ1面
5. ロゴ4面（シーン6）
6. 多言語WBGT指針（シーン3）
7. （あれば）熱中症アラート → 大雨警報 → 1へ

【シーン1 時刻下白帯】
256枠を連ねて左へ流す。順は固定:
1) 鴻治組横ロゴ 256（kohji_foot.png）
2) WBGT文言 256（例: 【警戒】定期的に休憩）
3) 工事名 512（令和7年度 安芸南部山系深山の滝川上流支川砂防堰堤他工事）
この3つを1セットにして繰り返す。ロゴと文言の間に工事名を挟まない。

【コンテンツ末尾ロゴ（気象・暑さ指数・4日予報）】
- 末尾は鴻治組ロゴ 128 を1面だけ
- 緑十字は末尾に並べない
- 白帯の空枠数は末尾ロゴ数と一致させる（ずれて空帯にしない）

【シーン6 ロゴ4面（このコンテンツ）】
512×128 を 128×128×4 で埋める。並びは固定:
  緑十字 | 鴻治組 | 緑十字 | 鴻治組
- 緑十字: green_cross.png を 128面いっぱいに cover
- 鴻治組: kohji_logo.png を 128面いっぱいに cover（左右余白は切る。マーク＋KOUJi が面に収まる）
- 白地。列間の黒線を出さない
- 2周して次シーンへ

【やらないこと】
- 庄原現場フォルダ / hiroshima_koujigumi の上書き
- WBGT色・段階名・指針文の独自変更
- 存在しない市区町村コードを作る
- 公式ロゴの再描画・勝手な生成
- git commit / push（指示があるまで）

【完了条件】
- 時刻下白帯が ロゴ256 → WBGT256 → 工事名512 の順
- 気象〜予報の末尾は鴻治組1面。白帯が空にならない
- シーン6が 緑十字|鴻治組|緑十字|鴻治組
- データが呉 67511 / 表示が熊野町
- 変更ファイルと確認用URLを短く返す
```
