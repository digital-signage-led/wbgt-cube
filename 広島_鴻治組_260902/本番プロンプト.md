【キャンバス】
- 本番: 4面 512×128。右端ロゴ列なし（layout-512）
- 列幅 128、ギャップ 0。勝手にレスポンシブ化しない
- 確認: ?layout512=1&native640=1 ／ 単体 ?only=1 〜 ?only=5
- 作業フォルダ: 広島_鴻治組_260902
- デプロイ先フォルダ名: hiroshima_koujigumi_kumano（庄原 hiroshima_koujigumi と別）

【現場】
- 会社: 株式会社鴻治組
- 工事名: 令和8年度 安芸南部山系深山の滝川上流支川砂防堰堤他工事

- 警報市区: 3410300 安芸区

【画像】
- 128面・縦型: ./assets/kohji_logo.png（マーク＋KOUJi。横長余白あり。128面は object-fit:cover で面いっぱい）
- 下帯・横型: ./assets/kohji_foot.png（マーク＋KOUJi＋株式会社＋鴻治組。上下余白を帯高さいっぱいに拡大）

1. 時刻（シーン1）
2. 気象観測（シーン2）＋末尾ロゴ1面
3. 暑さ指数 / WBGT（シーン4）＋末尾ロゴ1面
4. 4日予報（シーン5）＋末尾ロゴ1面
5. 多言語WBGT指針（シーン3）
6. 気象警報・注意報（安芸区に発表中のものがあるときだけ）

※ 熱中症アラートは出さない
※ 警報は安芸区に発表があるときだけ本番ループ末尾に表示（デモ専用URLは使わない）

- 緑十字は末尾に並べない
- 白帯の空枠数は末尾ロゴ数と一致させる（ずれて空帯にしない）

- ロゴ4面（緑十字｜鴻治組）シーンの復活（指示があるまで）
- git commit / push（指示があるまで）

【完了条件】
- 時刻下白帯が ロゴ256 → WBGT256 → 工事名512 の順
- 気象〜予報の末尾は鴻治組1面。白帯が空にならない
- シーン6（ロゴ4面）が無い
- データが呉 67511 / 表示が安芸区
