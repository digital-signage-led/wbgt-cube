## 確定構成（この形で安定・再来しない）

**取得経路（正）**：ブラウザ → **GAS中継** → EDAM。
無料CORSプロキシ（cors.eu.org / allorigins / jina）は**判断から外す（既定オフ）**。

**3層防御で「取得中」に落とさない**
1. **取得層**：GAS中継を正経路に。GASは①空応答もキャッシュ ②直前の正常値を永続保存。
2. **表示層**：`edam-ssc.js`＋HTMLが直前値を保持し、一時失敗では「取得中」にしない。
3. **監視層**：GASの`watchdog()`が更新停止をメール通知（5分トリガー）。

**数値パラメータ（確定）**
- GAS `CACHE_TTL_SEC = 15`（EDAM叩き 約5,760回/日＝個人上限 約2万回/日の約29%）
- `refreshMs = 1000` は据え置き（クォータを食うのはGASのEDAM叩きだけ。画面は1秒でよい）

## 実物ファイルの構造（改修時はここを見る）

### index-4face.html
- `SignageConfig.edamSsc` 設定ブロック
  - **`gasUrl: ''`** ← ★ここにデプロイしたGAS URLを入れる（本番接続の要）
  - `corsProxy: 'off'`（緊急時のみ `?sscProxy=`）
  - `apiHost` / `apiPath` / `idNum` / `refreshMs:1000`
- `fetchEdamSsc_()`：取得本体。`EdamSsc.fetchValues` を呼ぶ
  - `gasUrl: query.get('sscGas') || EDAM_SSC_CFG.gasUrl` ← `?sscGas=<URL>` で先にテスト可
  - 失敗しても`lastSscValues_`に値があれば「取得中」にしない＝**表示層の直前値保持は実装済み**（猶予期限なしの永久保持）
- `applySscValuesToDom_()`：DOM反映＋`lastSscValues_`更新
- `buildSscMetaTrack_()`：下部テロップ（`時刻`は`lastSscValues_.time`＝古い値なら時刻も古いまま＝目視で鮮度が分かる）

### edam-ssc.js（グローバル`EdamSsc`）
- 取得順：`fetchRow()` 内で ①local `/api/ssc`(github.ioではスキップ) → ②`gasUrl` → ③CORSプロキシ(**既定オフ**) → ④直叩き(CORSで失敗)
- `fetchViaGas_()`：GAS取得。fetch失敗時は**JSONPフォールバック**
- `firstRowFromData()`：`[...]` / `{data:[...]}` / 単体`{Time...}` すべて対応（GASの`{source,idNum,data:[]}`ラッパーもOK）
- `extractJsonPayload()`：HTML/空/不正配列を弾く

### gas/gas_edam_ssc_proxy.gs（安定版）
- `doGet()`：TTL内キャッシュ返し→切れたらEDAM1回→有データはキャッシュ＋`ssc_last_`永続保存／空は直前値を返す＋キャッシュ（**空でもキャッシュ＝クォータの穴を封鎖**）
- `CACHE_TTL_SEC = 15`
- `buildSscPayload_()`：`{source:'edam-ssc'|edam-ssc-stale, idNum, updatedAt, data:rows}`
- `respond_()`：`callback`ありでJSONP、なしでJSON
- `watchdog()`：EDAMを直接叩き、空/異常なら`notifyOnce_`（1時間に1回・`NOTIFY_TO`宛）
- **`NOTIFY_TO`** をデプロイ前に自分のGmailへ変更

### server.js（ローカル確認専用・本番非関与）
- `node server.js` → `http://127.0.0.1:PORT/index-4face.html?only=ssc`／`/api/ssc/2526`
- **github.ioでは動かない**。ローカル検証専用。

## 絶対に守るルール（再来防止）
1. 正経路は**GAS中継**。無料CORSプロキシを取得順の判断に**戻さない・既定で使わない**。
2. 個人GASのUrlFetch上限は**約2万回/日**（※数値は変わりうる／要公式確認）。
   **1秒ポーリングで毎回EDAMを叩く設計にしない**。TTL15秒キャッシュ前提。
   **空応答`[]`の間もキャッシュ**する。
3. 取得が一時失敗しても**即「取得中」にしない**。直前の正常値を保持する。
4. **「NetworkにJSONが見える」だけで取得成功と判断しない**。判定はConsoleとDOM。
5. 「取得中」の原因説明は必ず**第1段階（空配列=データ未到着）**と**第2段階（CORS＋予備不通）**を分ける。
6. 騒音振動(EDAM SSC)を**WBGT(環境省→GAS)と混同しない**。
7. **監視(watchdog)を外さない**。
8. 現場名は**千葉市新港清掃工場更新整備工事**。
9. 未確認は「未確認」と明記。推測で事実を上書きしない。
